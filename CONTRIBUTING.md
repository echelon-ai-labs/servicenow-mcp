# Contributing

## Security Guidelines

- Never commit real credentials or tokens.
- Keep local secrets only in `.env` and commit only `.env.example` placeholders.
- Rotate exposed credentials immediately.
- Review your diff before commit for keys, passwords, cookies, and instance-specific URLs.

## Language and Documentation

- Keep user-facing comments and documentation in English.
- If a feature requires multilingual behavior (for example, keyword matching), document the intent in English.
